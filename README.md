## What I'm building

### ₹ Rupee Engine *(private)*
A Python system for analysing the Indian equity market and building portfolios from it, with a React UI on top. Built around async data pipelines, PostgreSQL, and backtesting that tries to be honest about what works.

- Scores the NSE universe with pluggable algorithms and turns the scores into risk-aware portfolios, with transaction costs modelled in.
- It's my own daily driver: **I've grown ₹50K into ₹70K with it** so far. A personal result, not a promise and not advice.
- 1,000+ commits since early 2026 and still my main project.

**Stack:** Python · asyncio · httpx · FastAPI · PostgreSQL · Alembic · scikit-learn · Cython · React 19 · TypeScript · Tailwind · TanStack Query · Docker

### 🧪 [System Design Playground](https://github.com/tejas-k3/system_design_playground)
Sketch a system, send traffic at it, watch it break, then fix it. Drag servers, caches, databases and queues onto a canvas and press Play to see queues fill, connection pools run dry and retries pile up.

- **Go** backend: a deterministic discrete-event simulation engine with a REST API and WebSocket live sessions.
- Guided challenges start from a broken design and score your fix from one to three stars.
- React + TypeScript frontend; run it with `make up`.

**Stack:** Go · WebSocket · React · TypeScript · zustand · roughjs · Docker

### 🧰 [Job Applier](https://github.com/tejas-k3/job-applier)
Chrome extension that fills repeated job-application fields from one profile and resume. It never clicks Submit, and it stops at auth, CAPTCHA and anything it doesn't recognise.

**Stack:** TypeScript · WXT · Chrome Extension (MV3)

### 🥋 BugDojo *(planning)*
A CLI that seeds realistic, verifiable bugs into your own code as graded challenges, to get better at reading code skeptically.

**Stack:** Python

### 🏆 [most-commits](https://github.com/tejas-k3/most-commits) *(archived)*
A quirky experiment: push a single GitHub repo to **111,111,111 commits** using empty commits, `commit-tree` plumbing and `git fast-import`. Archived after GitHub flagged the load it was putting on their systems.

**Stack:** Git · Shell
